# Diagnostic Screening and Homology Docking Parameters for the fipA Virulence Network
This repository hosts computational primer-assay configurations, experimental validation datasets, and homology-modeled virtual screening protocols used to track the prevalence of the fipA virulence gene and evaluate Lupeol as a potential inhibitor.

### Directory Structure
- `pcr_primers.txt`: Targeted oligonucleotide sequence structures for 16S rRNA assays and fipA cohort validation steps.
- `homology_docking_config.txt`: Homology modeling workspace records and AutoDock Vina search box center coordinates.
- `docking_results_matrix.txt`: Raw AMDock binding affinity values, estimated inhibitory constants (Ki), and ligand efficiency calculations for Lupeol.
